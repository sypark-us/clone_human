# CLONE HUMAN — 복제인간 전투 공장

한국어 브라우저 로그라이크 프로토타입입니다. 별도 빌드 과정 없이 `index.html`을 열면 플레이할 수 있습니다.

## 플레이 방법
1. 빈 슬롯 또는 교체할 슬롯을 클릭합니다.
2. 보상 모듈 3개 중 하나를 선택합니다.
3. 웨이브 시작을 눌러 12턴의 자동 전투를 관찰합니다.
4. 웨이브를 클리어하면 새 모듈을 선택하고 생산 라인을 강화합니다.
5. 총 8개 웨이브를 클리어하면 승리합니다.

## 시스템
- 6개 생산 슬롯, 9종 모듈
- 슬롯을 왼쪽부터 오른쪽으로 실행
- 증폭기/시간 복제는 바로 앞 모듈의 행동을 추가 실행
- 채굴, 복제, 자폭, 회수, 부활을 조합해 연쇄 시너지 구축
- 브라우저에서 바로 실행, 외부 라이브러리 없음

## 온라인 플레이 (GitHub Pages)
저장소 Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
게시가 완료되면 `https://sypark-us.github.io/clone_human/` 에서 실행할 수 있습니다.

## 현재 범위
재미 검증을 위한 초기 MVP이며 그래픽, 밸런스, 저장 기능은 추후 개선 대상입니다.
